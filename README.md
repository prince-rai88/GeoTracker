# 🌍 GeoTracker

GeoTracker is a full-stack real-time location tracking web application.

## 🚀 Features

- Live device location tracking
- Historical location storage
- Interactive map visualization
- CSV export of location history
- Authentication system
- Tracking toggle (Start/Stop)

---

## 🛠 Tech Stack

### Frontend
- React
- React Router
- Leaflet Maps

### Backend
- Django
- Django REST Framework
- Token Authentication

---

## ⚡ Setup Instructions

### Backend

cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

---

### Frontend

cd frontend
npm install
npm run dev

---
